# App de Investimentos

Acompanhamento pessoal de carteira: aportes, dividendos, rendimento e reservas para objetivos.

- Especificação completa: [SPEC.md](SPEC.md)
- Schema do banco: [supabase/migrations](supabase/migrations)
- Esboço das telas: [docs/telas](docs/telas)

## Configuração
1. Copie `.env.example` para `.env.local` e preencha com os dados do projeto Supabase.
2. Aplique as migrations no Supabase.
